Project stack

One platform, multiple layers.

Time Manager combines a Phoenix/Elixir backend, a Vue 3 web application, a Cordova Android app, and a Docker-based deployment architecture. Each layer has a clear responsibility, but they work together as one operational system for time tracking, team visibility, payroll support, and user management.

Backend layer

Phoenix + Elixir + Ecto + PostgreSQL

API Core

The backend exposes the business logic through JSON endpoints and manages authentication, user access, schedules, teams, and payroll features.

Phoenix Elixir

Data access

Ecto handles queries, schema validation, and persistence to PostgreSQL. The app keeps business rules in the context layer and database migrations.

Ecto Repo Migrations

Security

Authentication uses signed JWTs with a secure signer, cookie handling, CSRF validation, and role-based checks for manager/admin access.

Joken Bcrypt CSRF

Runtime

The server runs on Bandit in a release-ready setup, exposing a structured API consumed by both the web and mobile clients.

Frontend layer

Vue 3 + Vite + Bootstrap

UI framework

Vue 3 provides a reactive client-side architecture for dashboards, forms, and role-based screens.

Styling

Mobile layer

Cordova Android + local storage + notifications

Packaging

The app is packaged with Apache Cordova for Android and renders the same core interface as the web app.

Cordova Android

Persistence

SQLite storage is used to keep data available on the device, with support for secure local storage patterns.

SQLite Secure Storage

Device features

The mobile app integrates network awareness, vibration, notifications, and local-device interaction.

Local notifications Vibration Network

Infrastructure layer

Docker + PostgreSQL + cloud hosting

Containers

Docker Compose orchestrates the database, API, and frontend services in a coherent development and deployment stack.

Docker Compose

Database

PostgreSQL stores users, teams, timesheets, policies, tasks, and secure account data.

Postgres SQL

Runtime delivery

The application is served with containerized deployments and can sit behind NGINX and GCP firewall rules in production.

NGINX GCP

Environment

Shared environment variables control database credentials, host config, and security-critical secrets.
