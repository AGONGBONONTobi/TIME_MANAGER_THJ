Technical stack deep dive

This application is intentionally split into separate layers so that business logic, user interaction, mobile distribution, and infrastructure concerns remain clear and manageable throughout development.

Backend responsibilities

  • Handles authentication, authorization, and session validation.
  • Exposes JSON endpoints for user, team, and time-related workflows.
  • Applies business rules in the Elixir context and controller boundaries.
  • Persists data with PostgreSQL through Ecto migrations and schemas.

Frontend responsibilities

  • Provides interactive dashboards and role-aware navigation.
  • Uses Vue Router for page transitions and route protection.
  • Consumes backend APIs with Axios and formats results for the user.
  • Uses responsive styling for desktop and tablet operation.

Mobile responsibilities

  • Package and deploy a Cordova Android app with native shell support.
  • Provide immediate local feedback with splash screens and device notifications.
  • Use local storage and secure storage patterns for offline-first mechanics.
  • Support network-aware, device-aware user interactions.

Infrastructure responsibilities

  • Containerizes services with Docker Compose for predictable local and cloud setup.
  • Runs PostgreSQL as the central application data store.
  • Provides gateway and firewall protections in production layers.
  • Maintains environment configuration, secrets, and deployment variables.
